# Comparison evidence

These images are fixed Editor review views. The original set records the four-way comparison; the D v2 set records the selected B202-inspired direction after expansion and venue polish.

- Concepts A, B, and C use the same camera offset, target height, 60-degree field of view, lighting, room size, and shared prop palette.
- `lobby-wide.png` uses an 85-degree field of view to show all three entrances from the shared lobby.
- Concept D is intentionally larger and tiered. `concept-d-b202-from-entrance.png` shows the descent from the upper entrance toward the stage, and `concept-d-b202-from-stage.png` shows the six seating terraces and radial desk layout from the stage.
- `concept-d-v2-final-entrance.png` shows the widened 96-seat room, four seating blocks, and the stage screen from the D entrance.
- `concept-d-v2-final-stage.png` shows all six terraces, the three stair lanes, and the four-block seating layout from the stage.
- `concept-d-v2-final-stage-posters.png` shows the presentation screen, speaker, lectern, and one wall of replaceable poster surfaces.
- The images verify saved Scene composition only. Avatar movement and runtime BEE loading require the separate manual smoke test.
